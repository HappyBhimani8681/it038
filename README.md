# Hello World Program

A simple introductory script that prints `"Hello, World!"` to the console.

## Code Example

```python
print("Hello, World!")
```

## How to Run

1. Make sure Python is installed on your machine.
2. Save the code above into a file named `hello.py`.
3. Open your terminal and run:

```bash
python hello.py
```

## Expected Output

```text
Hello, World!
```
